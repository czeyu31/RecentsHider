# Design System: System Tool

双主题设计系统。同一套骨架、两个主题包，运行时在设置中切换。

## 1. 视觉主题与氛围

### Paper（纸本）
一间安静的建筑师工作室：暖米白纸面、墨黑正文、朱红单点强调。不用卡片、不用阴影、不用大圆角。信息靠 1px 横线与点状引导线组织，列表用 01/02/03 编号。密度 4/10，变体 6/10，动效 4/10（位移与透明度，无弹性）。

### Graphite（石墨 · 雾玉）
夜里的精密仪器：冷石墨底、去饱和雾玉绿、软面板配顶部 1px 高光模拟边缘折射。留白最大，非对称网格。密度 3/10，变体 8/10，动效 8/10（弹簧物理）。

## 2. 色彩令牌

### Paper
- Canvas 纸面 (#F1EDE3) — 主背景
- Paper Lift 纸光 (#FBF8F1) — 左上径向提亮
- Paper Shade 纸影 (#E7E1D2) — 右下径向压暗
- Ink 墨黑 (#151410) — 主文字
- Ink Muted 墨灰 (#4B4840) — 次级文字
- Ink Faint 墨淡 (#8A8577) — 标签、元信息
- Rule 横线 (rgba(21,20,16,.13)) — 结构分隔
- Rule Strong 强线 (rgba(21,20,16,.26)) — 输入框、虚线引导
- Vermilion 朱红 (#AE4327) — 唯一强调色，只用于状态、箭头、危险动作、主操作下划线

### Graphite
- Canvas 石墨 (#0F1214) — 主背景
- Panel Top 面板上 (#1C2125) / Panel Bottom 面板下 (#171B1E) — 面板渐变
- Hairline 发丝线 (rgba(255,255,255,.065))
- Hairline Strong 强发丝 (rgba(255,255,255,.12))
- Ink 主文字 (#E9EDEC)
- Ink Muted 次文字 (#96A0A1)
- Ink Faint 淡文字 (#68716F)
- Jade 雾玉 (#8FB3A4) — 唯一强调色
- Jade Dim 雾玉罩 (rgba(143,179,164,.14)) — 开关底、图标底
- Jade Glow 雾玉光 (rgba(143,179,164,.55)) — 状态点光晕

### 共同禁令
不使用纯黑 #000000，不使用紫蓝渐变，不使用霓虹外发光，强调色饱和度低于 80%，全应用只有 1 个强调色。

## 3. 排版

- Display：系统字族（MiSans / Roboto）— 字重 500，字距 -0.03em
- Body：系统字族 400 — 行高 1.55，最大 30ch
- Mono：Roboto Mono — 所有数字、包名、版本号、地址，启用 tabular-nums

修订记录（2026-11-11）：原定 Outfit + JetBrains Mono，真机验证后更换，原因是两个已证实的问题——
1) Outfit 不含 CJK 字形，中文走系统回退时字重不生效，渲染成发丝级字重、整体发虚；
2) JetBrains Mono 的零是点状零（oval + 中心点），31sp 大数字上看起来像字符坏掉。
可变字体必须显式传 `FontVariation.Settings(FontVariation.weight(n))`，否则所有字重塌到同一个默认实例。
Outfit 与 JetBrains Mono 仍保留在 `res/font/` 备用。
- 标签：JetBrains Mono 9.5–11sp，字距 0.2em，全大写

### 字阶
- H1 状态主标题：Paper 44sp / Graphite 32sp，字重 500，字距 -0.035em
- 页面标题：22–23sp，字重 500，字距 -0.03em
- 大数字：Paper 34sp / Graphite 31sp，Mono，字重 400
- 正文：13sp，字重 300
- 列表主行：14.5sp，字重 400
- 元信息：9.5–10.5sp，Mono

## 4. 组件

### 按钮
- Paper：文字按钮 + 1.5sp 朱红下划线，无填充无圆角；次要按钮 1px 描边矩形
- Graphite：填充 13dp 圆角，Jade 底 + #0C1310 文字；次要按钮 1px 发丝描边 + 2% 白底
- 两者按下态：位移 1dp + 透明度 0.92，时长 90ms

### 面板/卡片
- Paper：无面板。区块之间用 1px 横线，或 1.5sp 墨黑强线做章节起始
- Graphite：20dp 圆角，渐变填充 + 1px 发丝描边 + 顶部居中 1px 高光（left 14 / right 14，透明→白 20%→透明）

### 开关
- Paper：34×19dp 方角，关闭时空心描边 + 11dp 方形滑块（墨淡），开启时朱红实底 + 纸白滑块
- Graphite：38×22dp 药丸，关闭时 8% 白底 + 14dp 圆点，开启时 Jade Dim 底 + Jade 圆点 + 10dp 光晕

### 输入
- Paper：无框，仅 1px 底线
- Graphite：44dp 高，14dp 圆角，面板渐变底 + 发丝描边

### 空状态 / 加载
不使用圆形转圈。骨架条用与最终布局同尺寸的 2px 横线做呼吸（Paper）或面板底 8% 白做流光（Graphite）。

### 图标
全部自绘，统一 1.5sp 描边，24×24 viewBox，圆头端点。不使用 Material 图标库默认形状。

## 5. 布局

- 基准栅格：左右边距 Paper 30dp / Graphite 24dp
- 首页非对称双卡：宽 1.52 : 窄 1，间距 12dp
- 工具箱：两列，首项独占整行（100%），其余 44% 弹性
- 列表行高：Paper 58dp / Graphite 56dp
- 底部操作条固定 40dp 高，上边距 14dp，距安全区 30dp
- 触摸目标不小于 44dp
- 右滑手势导轨：屏幕右缘 34dp 宽区域，Paper 用 1.5sp 朱红竖排文字，Graphite 用 Jade 渐隐光带

## 6. 动效

- 弹簧：Graphite stiffness 380 / damping 32；Paper 不使用弹簧
- 入场：面板 8dp 上浮 + 淡入 240ms；列表行阶梯 30ms 递增
- 主题切换：整体颜色 320ms 过渡；Paper 额外做一条 1px 横线自上而下扫过
- 状态点：Graphite 呼吸（1.0 → 1.12，1800ms 无限循环）；Paper 静止
- 页面转场：共享元素做状态块与标题，其余淡入上浮 12dp
- 性能：只动 transform 与 opacity，不动 width/height/top/left
- 无障碍：跟随系统「移除动画」开关，开启后所有动效降级为 120ms 淡入

## 7. 反模式（禁止）

- 不使用 emoji
- 不使用 Inter 字体
- 不使用纯黑 #000000
- 不使用霓虹外发光与彩色光斑
- 不使用紫蓝 AI 渐变
- 不使用 3 等分卡片行
- 不使用嵌套超过 2 层的卡片
- 不使用圆形 loading 转圈
- 不使用填充式「New / Beta」药丸徽标
- 文案不用「一键解锁」「释放潜能」「极致流畅」类空话
- 不使用假数据凑数（99.99%、50%）；数字用真实量级
- 一个强调色，出现频率不超过每屏 3 处
